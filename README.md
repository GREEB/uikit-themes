# UI Kit themes for Deadlock

https://greeb.github.io/uikit-themes/

Pick a theme, change its colours and font, and install it into Deadlock from the browser (Chrome or Edge).
The page builds the theme on your PC from your own game files and writes it into your game's addons folder;
nothing is uploaded. Made with [UI Kit](https://github.com/GREEB/deadlock-uikit).
